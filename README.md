# Ruschagap

O'zbek tilida so'zlashuvchilar uchun rus tilini 0 dan B1/B2 darajagacha
o'rgatuvchi AI + gamified platforma.

**Maqsad:** 90 kun, kuniga 15–20 daqiqa, erkin muloqot.

## Texnologiyalar

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS + Framer Motion
- Supabase (keyingi fazada: auth + DB)
- OpenAI (Whisper + GPT-4o-mini), ElevenLabs (keyingi fazada)

## Ishga tushirish (lokal)

Node.js 20+ o'rnatilgan bo'lishi kerak.

\`\`\`bash
npm install
npm run dev
\`\`\`

Brauzerda: http://localhost:3000

## Muhit o'zgaruvchilari

`.env.example`ni `.env.local`ga ko'chiring va to'ldiring.
